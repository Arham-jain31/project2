# Task P3 - Arham Jain

Beginner-level React + Tailwind frontend for the P3 Home Page.

## Run the project

```bash
npm install
npm run dev
```

## Main React structure

App
- Header
- Hero
- About
- Project
- Gallery
- Articles
  - Card
- Tutorials
  - Card
- Footer

## P3 requirements covered

- React project
- Frontend only
- Parent -> children component architecture
- Articles stored in an array
- Articles displayed using map()
- Featured Articles
- Featured Tutorials
- Images
- Icons using lucide-react
- Daily Insider signup
- Footer with Explore, Support and Stay Connected
- .gitignore contains node_modules/
- No server.js
- No custom CSS styling; Tailwind utility classes are used

## Important

Do not commit node_modules/ to GitLab.
